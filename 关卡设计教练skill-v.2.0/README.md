## 1. 这是什么 / 不是什么

| | |
|---|---|
| **是** | 一套纯 Markdown 的「AI 提示词包」，角色是无人机教学关卡设计教练 |
| **干什么** | 每次只问一个问题、共 7 步；每步给优化建议与盲区提示，违反信条会「红牌打回」；最后产出 8 块蓝图 + HTML 三层要素清单 |
| **内置知识** | 航线规划 / 视觉定位（GPS 失效）/ 桥梁巡检三关的原理库、教学角度与常见误区 |
| **不是** | 不是网页、不是程序；**不生成 HTML 代码**，只出设计蓝图（文字 + 要素清单） |
| **依赖** | 零代码、零外部依赖、不联网、不含密钥与个人路径 |

### 它的教学信条（决定产出不会是大众模板）

1. **闭环教学**：原理 → 对比 → 难度 → 评价 → 综合任务，五阶段缺一不可
2. **对比必须量化**：≥3 个带单位、可观察、可解释的指标，拒绝「效果更好」这类空话
3. **飞行结果可视化**：改任一选择必须能看到无人机「实际怎么飞」，不能只甩一张指标表
4. **难度绑定原理**：只加操作压力与环境干扰，不许绕过原理通关，玩家始终是决策者
5. **界面与信息秩序**：原理按五类分类收进「原理」按钮默认折叠；界面须有明确风格约定
6. **确定性因果**：扣分必须写成确定公式，禁止随机判定、定性扣分与未定义基准
7. **跨步一致性**：7 步口述出现矛盾时，汇总前主动校准，并把每处校准列成「定稿校准记录」，不偷偷改设计

### 7 步会问你什么

| 步 | 只问这一个 |
|---|---|
| 1 定调与原理 | 主题 + 一句话核心原理（按「核心概念 / 影响因素 / 关系与权衡 / 常见方法与适用条件 / 本关误区」五类列全） |
| 2 对比与指标 | 交互方式 + ≥3 个量化指标（带单位） |
| 3 难度与防跳步 | 低 / 中 / 高怎么加压，为什么绕不过原理 |
| 4 游戏化与沉浸 | 任务背景、正反馈、动态事件、成就系统 |
| 5 界面风格 | 配色 / 布局 / 视觉基调 / 控件样式 + 五区规格 + 折叠原理按钮 |
| 6 综合任务与评价 | 最终任务、环境约束、分项权重（合计 100%） |
| 7 生成蓝图 | 先跑闭环自检，再输出完整蓝图 |

> 一次性把 7 步信息全给齐，可以跳过逐问直接出蓝图（包内叫「逃生舱」），但信条校验照做。

### 最终产出长什么样

8 个板块：① 基础信息与核心原理 ② 游戏化背景与动态事件 ③ **飞行结果可视化展示区** ④ 量化指标对比表 ⑤ 三阶难度与防跳步 ⑥ **界面风格与信息呈现** ⑦ 约束综合任务 ⑧ S/A/B/C 评分权重。末尾附 **HTML 制作要素清单**（场景地图层 / UI 层 / 交互逻辑层）与**定稿校准记录**。

## 2. 三步装好（WorkBuddy，最推荐）

### 第 1 步 · 解压

把 `skylab-level-coach-v2.0.0.zip` 解压到：

```
C:\Users\你的用户名\.workbuddy\skills\
```

解压完应该是这个结构（**注意别多套一层文件夹**）：

```
...\skills\skylab-level-coach\
    ├─ SKILL.md
    └─ references\
        ├─ blueprint-format.md
        ├─ coaching-playbook.md
        ├─ domain-knowledge.md
        └─ gotchas.md
```

> `.workbuddy` 是隐藏文件夹；若 `skills` 目录不存在，手动新建即可。
> 常见错误：解压后变成 `...\skills\skylab-level-coach-v2.0.0\skylab-level-coach\SKILL.md`，多套一层会认不到。

### 第 2 步 · 完全退出并重启 WorkBuddy

技能清单有缓存，**只新建对话不够**，必须重启应用让它重新扫描一遍。

### 第 3 步 · 新开对话调用（推荐显式点名，最稳）

```
@skill:skylab-level-coach 设计航线规划关
```

正确表现：从「第一步 · 定调与原理」开始，**每次只问一个问题**，并带优化建议与盲区提示。

## 4. 不用 WorkBuddy 也能用

**B · 其他支持 Agent Skills 的 AI 工具**

`SKILL.md` 是通用 Agent Skills 格式（`name` / `description` 为标准字段，`version` / `agent_created` 是 WorkBuddy 附加字段，一般被忽略）。把整个 `skylab-level-coach` 文件夹放进该工具的 skills 目录（例如 Claude Code 的 `~/.claude/skills/skylab-level-coach/`），保持 `references/` 与 `SKILL.md` 同级即可。

> 如实说明：跨平台兼容性未实测。

## 5. 五个最常见的坑

| 现象 | 原因 / 解决 |
|---|---|
| 只发或只拷了 `SKILL.md`，教练答得很泛 | 4 个 references 没带，领域库和陷阱库读不到 |
| 装完说触发词没反应 | ① 没重启 WorkBuddy ② 目录多套一层 ③ 应用侧「模型自动调用」被关 → 用 `@skill:skylab-level-coach` |
| 解压后路径不对 | 目标是 `...\skills\skylab-level-coach\SKILL.md`，不是 `...\skills\xxx\skylab-level-coach\...` |
| 想要它直接吐 HTML 网页 | 它按设计只出蓝图；HTML 需另一步实现，这是刻意保留的边界 |
| 担心教练把我的设计改了 | 不会悄悄改：每处保守校准都列在蓝图末尾「定稿校准记录」，一句话即可推翻 |
